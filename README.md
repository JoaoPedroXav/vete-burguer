# Vetê Burguer

Implementação estática da página Vetê Burguer baseada no Figma. Usa HTML, CSS e JavaScript, com imagens, ícones e fontes locais.

Site publicado: https://vete-burguer-joaop.jxavierr7.chatgpt.site/

Para visualizar, abra `index.html` no navegador ou sirva esta pasta com `python -m http.server 8000`.

Os botões abrem o cardápio da Brendi, a loja no iFood, o WhatsApp da Vetê Burger e o endereço no Google Maps. O botão do cupom copia `VETE10`.

O carrossel dos hambúrgueres passa automaticamente. Os cinco depoimentos mudam apenas pelas setas. Cada nome abre a avaliação original no Google. Os textos estão salvos em `script.js`, portanto não são atualizados automaticamente.
